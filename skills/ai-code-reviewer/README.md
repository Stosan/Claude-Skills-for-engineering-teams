# AI Code Reviewer

> **Skill name:** `ai-code-reviewer` · **Plugin:** `engineering-skills` · **Instructions:** [`SKILL.md`](SKILL.md)

## Overview

A forensic audit calibrated to the failure modes of AI code generation: confident incorrectness, hallucinated APIs and packages, subtle logic errors, and production-unsafe patterns that look correct on the surface. Use it on anything written by Copilot, Cursor, Claude, ChatGPT, Gemini, Codeium, Devin, etc.

## When to use it

- Reviewing a PR, diff or file produced by an AI coding assistant
- Checking whether AI-written code actually solves the stated problem
- Verifying that every imported library, method and config option really exists
- Deciding whether AI-generated code is safe to merge

## What to give it

- The code (paste, file path, folder, or `git diff`)
- The original task / ticket / prompt the AI was given (strongly recommended)
- Which AI tool generated it (optional — helps pattern-match known failure modes)

## What you get back

- **AI Code Review Report** with an executive summary and verdict
- Six-dimension review: Correctness, Bug Introduction, Bug Resolution, Faithfulness to Intent, Production Readiness, Hallucination Detection
- Issues ranked 🔴 Critical / 🟠 High / 🟡 Medium / 🟢 Low
- **Hallucination Registry** of non-existent APIs, params or packages
- Corrected code with line-by-line change notes, plus tests that should exist

## Example prompts

**1. Basic review**

```text
Cursor wrote src/payments/refund.ts. Review it — did it hallucinate anything, and is it production ready?
```

**2. Against the original task**

```text
Here's the Linear ticket and the code ChatGPT produced for it. Is it faithful to the requirements? <ticket> <code>
```

**3. Diff review**

```text
Review the AI-generated changes in `git diff main...feature/vat-engine`. Flag anything that would break in production.
```

**4. Hallucination hunt**

```text
Check every import and SDK call in services/notifications/ — Copilot wrote most of it and I'm not sure the Paystack/Termii methods it uses exist.
```

**5. Bug-fix verification**

```text
Claude claimed this patch fixes the duplicate-charge bug in webhook_handler.py. Does it actually fix it, and did it introduce anything new?
```

**6. Corrected version**

```text
Audit this Python function an AI wrote for computing PAYE, then give me a corrected version and the unit tests that would have caught each issue.
```

**7. Headless**

```text
git diff main...HEAD | claude -p "Use ai-code-reviewer on this diff. It was generated by Copilot. Output the report only."
```

## How to invoke

| Where | How |
|---|---|
| Claude Code CLI | Run `claude` in your repo and type any prompt above, or use the slash command `/ai-code-reviewer` (plugin install: `/engineering-skills:ai-code-reviewer`) |
| Claude Code Desktop | Code tab → open your project folder → type the prompt, or say *"Use the ai-code-reviewer skill to…"* |
| Claude app | Upload this folder as a `.zip` under Settings → Capabilities → Skills, then prompt normally |
| Headless / CI | `claude -p "Use the ai-code-reviewer skill to …"` |
